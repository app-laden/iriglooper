Hilfe

Bedienung

  • A: 1. Druck Aufnahme, 2. Druck Loop schließen und abspielen, danach Overdub an/aus. Jeder Overdub ist eine eigene Stufe.
  • B: letzte Stufe entfernen (während Aufnahme/Overdub: diese verwerfen).
  • C: einmal = Stop/Play (Loop und Drums gemeinsam), zweimal schnell = alles löschen.
  • D: einmal = Beat 1 starten bzw. laufende Drums stoppen; zweimal schnell = zwischen Beat 1 und Beat 2 wechseln (genau am nächsten Taktanfang). Sind die Drums aus, startet D zweimal direkt Beat 2. Weil die App kurz auf einen zweiten Tritt wartet, stoppt D einmal mit knapp einer halben Sekunde Verzögerung.
  • Zwei Beats: Jeder Beat hat eigenes Pattern bzw. eigene Loop-Datei, eigenes Tempo und eigene Lautstärke. Ist ein Loop aufgenommen, laufen beide Beats in dessen Tempo; hat ein Beat etwa das halbe oder doppelte Tempo, bleibt dieses Verhältnis erhalten (z. B. Halftime-Teil).
  • Ohne Pedal: Tasten 1–4 auf der Tastatur oder Kacheln anklicken.
  • Takt-Synchronisation: Laufen die Drums, beginnt und endet die erste Aufnahme immer an einem Taktanfang. Tritt A irgendwann im Takt vor dem Einsatz („BEREIT“, Countdown in Schlägen) – die Aufnahme startet am nächsten Taktanfang. Ein Tritt bis ein Viertel nach dem Taktanfang (also etwas zu spät) zählt noch zu diesem Takt. Zum Beenden A im letzten Takt treten: Die Aufnahme läuft bis zum Taktende und der Loop schließt sich nahtlos. Danach ist das Tempo an den Loop gebunden. Startest du die Drums erst zu einem fertigen Loop, passt sich das Tempo der Drums dem Loop an.
  • Eigene Drum-Loops: lizenzfreie WAV- oder MP3-Loops (z. B. von looperman.com) beim gewünschten Beat mit „Loop-Datei laden“ übernehmen. Steht das Tempo im Dateinamen (z. B. „Funk 95 BPM“), erkennt die App die Taktzahl selbst; sonst unter „Takte“ korrigieren. Die Dateien bleiben nur in diesem Browser auf diesem Gerät.
  • BlueBoard: beim Einschalten C gedrückt halten („MIDI over Bluetooth mode 2“), am Mac über Audio-MIDI-Setup → MIDI-Studio → Bluetooth verbinden. Die Tasten senden CC 20–23 und sind voreingestellt.
  • Klingen Overdubs zu spät, den Latenzausgleich erhöhen; zu früh, verringern.

Installation

  • Mac: Adresse in Chrome oder Edge öffnen (Safari kann kein MIDI). Chrome → ⋮ → „Streamen, speichern und teilen“ → „Seite als App installieren“. Danach läuft die App auch offline.
  • Windows: Chrome oder Edge → Symbol „App installieren“ in der Adresszeile.
  • iPad/iPhone: Die Browser dort können kein MIDI empfangen; die Pedale funktionieren nicht. Der Looper lässt sich nur per Bildschirm bedienen.
  • Neue Version: App mit Internet öffnen → grüne Leiste antippen.

Datenschutz & Haftung

Alle Aufnahmen, Einstellungen und eigenen Drum-Loops bleiben auf diesem Gerät im Browser; es wird nichts hochgeladen. Die Seite wird bei GitHub (GitHub Pages) bereitgestellt; GitHub verarbeitet beim Aufruf technische Daten wie die IP-Adresse.

Die App wird ohne Gewähr bereitgestellt. Nutzung auf eigene Verantwortung; für Schäden an Geräten, Gehör oder Daten wird keine Haftung übernommen. Lautstärke vorsichtig einstellen.
